# Which licence covers what

| Path | Licence | File |
|---|---|---|
| `scripts/` | MIT | [`LICENSE`](LICENSE) |
| `datasets/` | CC BY 4.0 | [`LICENSE-DATA`](LICENSE-DATA) |
| `docs/`, `README.md` | CC BY 4.0 | [`LICENSE-DATA`](LICENSE-DATA) |

Two licences because they are two different things: code wants the shortest possible terms,
data wants attribution and nothing else. Reasoning and the rejected alternative (ODbL) are in
[`docs/licence-decision.md`](docs/licence-decision.md).

GitHub's sidebar will report this as "unknown" because it looks for a single licence file and
finds two. This table is the authority.
