# Method

Everything here was obtained by script, and the scripts are in `scripts/`. Nothing was
hand-transcribed, and nothing was generated by a model. Where a number appears in a derived
table, the derivation is in the repository.

## Principle: refuse to guess

The hard part of this work is never the download. It is joining sources that disagree about
what a municipality is called.

| Source | Key it uses |
|---|---|
| Municipal Money | demarcation code (`EC102`, `DC10`) |
| AGSA | slug (`1-matatiele`) + district name + province |
| IEC | display name (`NMA - Nelson Mandela Bay`, `EC442 - Umzimvubu`) |
| Stats SA P9115 | municipality and district name, as text |

The join in `scripts/analyse_financial_performance.py` normalises names (strip the code
prefix, drop "municipality/district/local/of/the", strip punctuation), then:

1. tries an exact (name, province) pair;
2. falls back to a name-only match **only if it is unique**;
3. drops anything still ambiguous, and counts it.

It prints what it dropped. That is the difference between a join and a guess.

## Result of the join (2026-11-10)

```
200 live municipalities in scope
  11 without Municipal Money finance
  21 without an unambiguous AGSA match
  20 without an unambiguous IEC council
209 of 232 IEC councils matched by the dedicated IEC↔AGSA joiner
```

## Two bugs found while doing this, recorded so they are not repeated

1. **Code prefixes vs punctuation.** Stripping punctuation *before* stripping the code prefix
   turns `EC442 - Umzimvubu` into `ec umzimvubu`, and 193 of 200 councils fail to match. Strip
   the prefix first, on the original string.
2. **Metric definitions are in the data, not in the name.** Municipal Money ships a `formula`
   field per indicator. Reading it changed two conclusions:
   - `capital_budget_spending` is `(actual − budgeted) / budgeted × 100`. **Negative means the
     capital budget was underspent.** Nearly every group is negative.
   - `repairs_maintenance_spending` is R&M / (property, plant and equipment + investment
     property) — an asset-renewal ratio, *not* a share of operating expenditure.

   Both had plausible-sounding wrong descriptions written down before the formula was read.

## Rate limiting, honestly

AGSA returns **HTTP 429** under a fast sequential sweep. At 0.15 s spacing that cost 18 of 257
auditees; `retry_ago_failures.py` re-fetches only the failures with `Retry-After` backoff and
merges them back. The sweep now runs at 0.6 s with 429 handling.

## Reproduction

```bash
python3 scripts/fetch_municipal_money.py           # 3 requests → datasets/municipal-money/
python3 scripts/fetch_ago_outcomes.py              # 258 requests → AFSA audit opinions
python3 scripts/retry_ago_failures.py              # only if the sweep reported failures
python3 scripts/extract_fbs_from_p9115.py FILE.xlsx  # needs the Stats SA workbook
python3 scripts/analyse_financial_performance.py   # the join → a table
```

`extract_fbs_from_p9115.py` needs the P9115 workbook as an argument: download
`P9115_2022 Unit Data.xlsx` from `statssa.gov.za/publications/P9115/` (live at time of writing,
2026-11-15) or from the Wayback capture of 2024-06-29, then copy it to `/tmp` first —
`openpyxl` intermittently fails to open it in place on btrfs.

## What is not automated, deliberately

- Anything against a publisher whose terms prohibit it.
- Identification of ambiguous matches. 22 IEC councils still need a human; the tool lists them
  rather than picking.
- Interpretation. No script in here makes a causal claim.
